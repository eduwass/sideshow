Publish a whole session as an ordered collection. The confirmation view lists every post the collection would include — defaulting to all of them, in session order — and the server only accepts an explicit list of reviewed post ids, so nothing can be published or updated without that review. Each post stays its own section with its own surfaces and anchor: typed surfaces stay typed, sandboxed HTML is never flattened into the page, and a collection snapshot freezes the exact post versions and assets it included.
